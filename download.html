After you download

  1. Install

    Windows: run the installer. Mac: open the .dmg file and drag the app into Applications. Already installed? Install over it. Your profile and history are kept.

  2. Open and activate

    The first launch sets a few things up and can take a few minutes. Then enter the license key from your email.

  3. Set up and start

    Fill in your profile, add your resume, and start a short first run to see it work.

Installing

If your computer shows a warning

Moonshift is new, so Windows and macOS may ask you to confirm the first time you open it.

Windows: “Windows protected your PC”

Click More info, then Run anyway. You only need to do this once.

Mac: “can’t be opened” or “cannot verify the developer”

Open System Settings, go to Privacy & Security, scroll down and click Open Anyway next to the message about the app. Then open it again.

Linux: the AppImage will not start

Right-click the file, open Properties and allow it to run as a program. Or run chmod +x on the file in a terminal, then open it.

Requirements

What you need

A computer

Windows 10 or 11 (64-bit), macOS on Apple silicon or Intel, or 64-bit Linux.

Google Chrome

Moonshift applies in Chrome. Install it from google.com/chrome if you do not have it.

An internet connection

Needed during runs, and on first launch while Moonshift sets itself up.

Updates

Always up to date, never in your way

Automatic

Moonshift checks for updates when it opens and while it runs. There is nothing to download again.

Never mid-run

It waits until no run is going and nothing is unsaved, then updates and reopens.

Your data stays

Updates replace the app, not your profile, saved answers, history or logins.

Checked and safe

Every update is verified before it is installed. If anything goes wrong, the previous version keeps working.
