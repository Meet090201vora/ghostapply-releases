GhostApply is not a Chrome extension and not a staffed click-farm. It is a desktop window that starts an engine on your machine and drives Dice Easy Apply in Chrome you can see.

Inside the app

Four rooms. Nothing extra.

Apply

Platform, profile, keywords, location, max applications. Start. Watch Chrome.

Profile

Applicant details, resume, Dice email/password, Gemini API key — all editable by you.

History

Every job the engine touched, with status and a link back.

Gaps

Questions Gemini skipped. Fix the profile once; the next run is quieter.
